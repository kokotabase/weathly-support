WEATHLY

サポート

WEATHLY は、気象庁が発表する天気予報とアメダスの観測を、シンプルに見やすく表示する iPhone 向け天気アプリです。

お問い合わせ

不具合のご報告・ご要望は、以下の GitHub Issues からお送りください。

https://github.com/kokotabase/weathly-support/issues

よくある質問

予報はどこから取得していますか？

すべて気象庁ホームページで公開されているデータです（天気予報・週間天気予報・地域時系列予報・アメダス・平年値）。気象庁の予報を加工せずに表示しており、本アプリが独自に予報を行うことはありません。

「平年」タブは予報ですか？

予報ではありません。気象庁が公表している平年値（過去の観測の平均）を、来週以降の日付に並べています。

現在地は使いますか？

使いません。地点はアプリ内の一覧から選択します。

データが表示されない／古いままです

通信環境をご確認のうえ、画面の「再読み込み」または「設定」の更新ボタンをお試しください。通信が戻ると自動で再取得します。

保存データを消したい

「設定」→「保管した予報と観測を削除」で消去できます。

データの出典

  • 気象庁ホームページ（政府標準利用規約 第2.0版に準拠）
